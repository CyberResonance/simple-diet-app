# MacroMaster - Simple Diet App

A modern, interactive diet application built with **React** and **Vite**, featuring a premium "Glassmorphism" UI design.

## 🌟 Features

- **Interactive Interview**: A step-by-step user data collection process (Age, Height, Weight).
- **Dynamic Dashboard**: personalized results view based on user input.
- **Modern UI**: responsive design with glassmorphism effects, smooth gradients, and animations.
- **Tech Stack**: React, Vite, Vanilla CSS (with responsive utilities).

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/simple-diet-app.git
   ```
2. Navigate to the project directory:
   ```bash
   cd simple-diet-app
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

Start the development server:

```bash
npm run dev
```

## 🛠️ Build

To build the application for production:

```bash
npm run build
```

The artifacts will be in the `dist` folder.
